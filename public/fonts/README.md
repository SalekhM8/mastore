# Brand fonts

Drop the licensed Couture Narrow web files here and the site picks them up automatically:

- `CoutureNarrow-Bold.woff2` (and optionally `.woff`)
- `CoutureNarrow-Regular.woff2` (and optionally `.woff`)

Source: Envato Elements, "Couture – Modern Dynamic Narrow Sans Font" by funtypeco, licensed to the
Mastore HQ website project. Until the files exist, headings fall back to Big Shoulders Display.
